Sensibilidade à Inicialização & Múltiplos Restarts

O K-means é sensível às posições iniciais dos centróides e pode ficar preso em mínimos locais. A solução padrão é executar múltiplas reinicializações (restarts) ou usar o algoritmo K-means++.

2. Boas Práticas: Múltiplas Execuções (Restart) Pseudo-código da Aula 
# Estratégia de Múltiplos Restarts
melhor_SSE = Infinity
melhor_agrupamento = None

para i = 1 até 100:
    # 1. Inicializa centróides aleatórios
    centróides = inicializar_aleatorio(dados, k)
    
    # 2. Executa k-means até a convergência
    clusters = executar_kmeans(dados, centróides)
    
    # 3. Calcula dissimilaridade intracluster (SSE)
    sse_atual = calcular_SSE(dados, clusters)
    
    se sse_atual < melhor_SSE:
        melhor_SSE = sse_atual
        melhor_agrupamento = clusters

retorne melhor_agrupamento
Como funciona o K-Means++?
1. O 1º centróide é escolhido uniformemente ao acaso.
2. Cada centróide seguinte é sorteado com probabilidade proporcional a $D(x)^2$ (o quadrado da distância ao centróide mais próximo já existente).
Isso força os centróides a nascerem bem afastados uns dos outros, reduzindo drasticamente as chances de mínimos locais!
