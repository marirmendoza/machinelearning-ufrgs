Este é o pipeline mínimo de qualquer projeto de aprendizado supervisionado — não só do KNN. O que muda entre algoritmos é como a predição é feita: em vez de "olhar os k vizinhos e votar", uma árvore percorreria os nós internos, e uma rede neural faria uma sequência de multiplicações matriciais. Em todos os casos, a metodologia é a mesma: separar treino/teste, treinar, avaliar em dados novos, reportar métricas.
