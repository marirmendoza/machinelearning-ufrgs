Por que Normalizar?

Sem normalização, o atributo de maior escala vira o único critério de "proximidade" — como se o modelo dissesse "só ele importa".

👤

Cenário: classificar um novo indivíduo com idade = 25 e salário = R$ 5.000 como estudante ou engenheiro, usando k = 3.

Sem normalização
Salário domina — idade vira quase irrelevante
estudante engenheiro
Distância até o vizinho mais próximo d = |25−45| = 20 + |5000−6500| = 1500 = 1520
salário contribui com 98,7%
k=3 → predição 🔴 engenheiro
Com normalização (min-max)
Ambas features contribuem — idade volta a importar
estudante engenheiro
Distância até o vizinho mais próximo (agora outro!) d = |0,16−0,16| = 0,00 + |0,65−0,08| = 0,57 = 0,57
45%
55%
↑ contribuição média entre os 3 vizinhos
k=3 → predição 🔵 estudante
⚠️
Sem normalização, você está implicitamente dizendo ao modelo que o atributo de maior escala é o único que importa. Se salário varia de R$ 800 a R$ 7.000 e idade de 19 a 45, uma variação de 1 ano vale 1000× menos que uma variação de R$ 1.000 no cálculo de distância — a idade é praticamente ignorada. Normalização (min-max, z-score) coloca todos os atributos numéricos na mesma escala antes do treino.
