Min-Max vs. Standard Scaler

Duas técnicas para colocar tudo na mesma escala — fórmulas simples, geometrias diferentes.

📏 Normalização Min-Max

Transforma os valores para o intervalo [0, 1]. Usa o menor e o maior valor observados.

x' = ( x − min ) / ( max − min )
📊 Padronização (Z-score)

Transforma para média 0 e desvio padrão 1. Usa a média e o desvio padrão da amostra.

x' = ( x − μ ) / σ

Dados originais: escalas muito diferentes — salário tem mais de 300× a magnitude da idade. Isso quebra qualquer algoritmo que use distância.
🎯
Qual escolher? Na prática, teste ambos e compare o desempenho — o custo é baixo. Min-Max preserva a distribuição original mas é sensível a outliers (um valor extremo esmaga todos os outros). Standard é mais robusto e tende a funcionar bem quando os dados são aproximadamente normais. Existe ainda RobustScaler (usa mediana e IQR), útil quando há muitos outliers.
