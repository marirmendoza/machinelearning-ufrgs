Perceptron vs. Sigmóide

Após calcular a soma s, o neurônio precisa decidir se irá "disparar" (ativar). Existem diferentes funções de ativação para isso.

-5.0

Função Degrau (Perceptron)

f(s) = 1, se s ≥ 0
f(s) = 0, caso contrário
f(s) = 0

Função Sigmóide

f(s) = 1 / (1 + e⁻ˢ)
f(s) = 0.000
💡
A função degrau é rígida, causando saltos abruptos. A sigmóide tem uma transição suave, permitindo que a rede entenda não apenas "sim/não", mas também o grau de incerteza. Além disso, ela é diferenciável (tem derivada contínua), o que é essencial para o algoritmo de aprendizado.
