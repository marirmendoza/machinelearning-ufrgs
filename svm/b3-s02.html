O Efeito do Parâmetro C

Explorando o impacto do hiperparâmetro de penalização C no compromisso entre acurácia no treino e capacidade de generalização.

Comportamento de C em Dados Ruidosos:
• C pequeno (ex: 0.01): Tolera mais violações na margem $\to$ Margem maior $\to$ Modelo mais simples e estável (maior viés, menor variância).
• C grande (ex: 100): Penaliza fortemente qualquer erro $\to$ Tenta classificar tudo perfeitamente $\to$ Margem menor (risco de overfitting ao ruído).
1. Fronteira e Margem sob Diferentes Valores de C
C = 0.01 <------------------------------> 100: 1.0
2. Desempenho e Diagnóstico
Acurácia no Treino: 90%
Acurácia no Teste: 88%
Mova o slider para experimentar o comportamento de C.
Observação Importante:
Ao aumentar $C$ com ruído presente, note como a acurácia de treino pode subir para 100%, mas a acurácia de teste cai. O modelo tenta desesperadamente se ajustar aos pontos anômalos!
