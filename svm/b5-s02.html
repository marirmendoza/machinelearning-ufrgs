Grid Search, Pipeline & Comparação (SVM vs KNN vs Árvore)

Sintetizando a escolha prática de hiperparâmetros, pipelines com normalização e comparando os 3 grandes algoritmos da disciplina.

A Prática do Aprendizado de Máquina com SVM:
• Seleção de $C$ e $\gamma$ por Validação Cruzada: Não escolhemos hiperparâmetros no conjunto de teste! Usamos GridSearchCV.
• Normalização Indispensável: Como a margem e o kernel dependem de distâncias, StandardScaler() é obrigatório antes do SVM!
1. Matriz de Validação Cruzada (Grid Search C × γ)
C \ γ γ = 0.01 (Baixo) γ = 0.1 (Médio) γ = 1.0 (Alto)
C = 0.1 0.72 0.81 0.83
C = 1.0 0.80 ⭐ 0.94 0.89
C = 10.0 0.82 0.91 0.76 (Overfitting)
// Pipeline Recomendado no Scikit-Learn:
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

model = Pipeline([
  ("scaler", StandardScaler()),
  ("svm", SVC(kernel="rbf", C=1.0, gamma=0.1))
])

Síntese da Disciplina:
O SVM oferece uma das fronteiras com melhor capacidade de generalização da literatura, mas exige obrigatoriamente padronização prévia dos dados e ajuste cuidadoso de $C$ e $\gamma$.
