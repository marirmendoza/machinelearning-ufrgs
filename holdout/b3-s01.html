Train / Validation / Test

Se você usa o teste para escolher o melhor modelo, ele deixa de ser teste. Introdução ao holdout de 3 vias.

🎯

Cenário: comparamos KNN com k = 1, 3, 5, 7, 9. Queremos escolher o melhor k e reportar uma estimativa honesta do desempenho final. Compare as duas metodologias.

Estimativa honesta. O teste foi "tocado" uma única vez, apenas no final, para avaliar o modelo já escolhido. É uma boa aproximação do que o modelo fará em produção. Note que 82% é menor que o 87% enganoso — e é o que você deve reportar.
🔒
A regra sagrada: o conjunto de teste é tocado uma única vez, no fim. Toda decisão sobre modelo/hiperparâmetros deve ser feita com validação. Se você "der uma olhada" no teste durante o tuning — mesmo indiretamente — a estimativa fica contaminada. Em datasets pequenos, essa disciplina custa dados preciosos; a solução é k-fold cross-validation, que veremos em uma aula futura.
