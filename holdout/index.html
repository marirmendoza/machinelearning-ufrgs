Avaliação de Modelos: Holdout

Profa. Mariana Recamonde-Mendoza

O modelo deve ser avaliado em dados que não foram usados no treino. Introdução ao método holdout — a estratégia mais simples para estimar generalização — usando KNN como algoritmo-base.
