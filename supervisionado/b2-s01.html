Aprendizado no Espaço de Entrada

Aprender = descobrir uma função que mapeia entrada em saída, a partir dos padrões das instâncias anteriores.

🐶🐱 Cachorro vs. Gato — 2 atributos, 12 instâncias cachorro gato
↑ instâncias de treino já rotuladas: cada ponto sabe se é 🐶 ou 🐱
1
Cada instância vira um ponto no espaço
Os atributos preditivos definem os eixos. Cada linha da tabela — um cachorro ou um gato — vira um ponto posicionado por (peso, altura). O rótulo aparece na cor.
2
O algoritmo aprende uma função f
A partir dos pontos rotulados, o algoritmo descobre uma regra que separa as classes. Essa regra é a fronteira de decisão — a materialização visível da função aprendida.
# função aprendida a partir das 12 instâncias: def f(peso, altura): if peso > 7: return "🐶" else: return "🐱"
3
Novos pontos são classificados pela função
Uma vez aprendida, a função responde para qualquer entrada nova. Clique em qualquer lugar da plotagem para adicionar um ponto e ver a predição.

Todo algoritmo de aprendizado supervisionado — KNN, árvores, regressão, redes neurais — está fazendo a mesma coisa: encontrar uma função que particiona o espaço de entrada de acordo com os padrões observados nos exemplos rotulados. O que muda entre algoritmos é o formato dessa fronteira (reta, curva, degraus, superfície complexa…) e como ela é encontrada.
