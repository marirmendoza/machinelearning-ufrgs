Programado vs. Aprendido

O mesmo problema, dois caminhos: quem descobre a regra?

🍎🍊

Problema: classificar cada fruta como maçã ou laranja a partir do peso (g). Temos 20 frutas rotuladas.

Sistema programado
Um humano escreve a regra
Você tem que descobrir manualmente o melhor limite de peso. Arraste o marcador ↔.
if peso > 175: return "maçã" else: return "laranja"
80g150g220g
175 g
Acertos: ?/20
📝 Se aparecer um novo tipo de fruta, você precisa reescrever a regra. Se os pesos mudarem (safra diferente), reescrever de novo.
Sistema aprendido (AM)
O algoritmo descobre a regra
Clique em Treinar e o modelo encontra o melhor limite a partir dos dados rotulados.
modelo = TreinaClassificador( dados="20 frutas rotuladas" ) limiar = modelo.aprendeu # ← descoberto!
80g150g220g
100 g
Acertos: 10/20
Aprendendo com os exemplos...
🎯 Se aparecerem novos dados, basta retreinar. O modelo se adapta — ninguém precisa reescrever regra nenhuma.
💡
Sistemas que são treinados para realizar uma tarefa, ao invés de serem explicitamente programados para tal. Essa é a essência do aprendizado de máquina: mover o esforço humano de codificar regras para coletar e rotular exemplos.
