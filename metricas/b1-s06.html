F1

Uma única métrica que combina precisão e sensibilidade — média harmônica que "pune" desequilíbrios entre as duas.

🟠 Células usadas no F1
Usa VP, FP e FN — ignora VN. Faz sentido: em datasets desbalanceados, os verdadeiros negativos podem ser abundantes e enviesar outras métricas.

F1 score

Média harmônica entre precisão e sensibilidade. Alto só quando ambas são altas.

F1 = 2 · ( P · S ) / ( P + S )
ou, em termos das células: F1 = 2 · VP / ( 2 · VP + FP + FN )
Aplicando aos dados = 2 · 45 / ( 2 · 45 + 10 + 5 )
= 90 / 105
≈ 85,7%

🔀
Por que média harmônica em vez de média simples? Se precisão = 90% e sensibilidade = 10%, a média simples seria 50% — parece razoável, mas o modelo é claramente péssimo (perde 90% dos positivos). Já a média harmônica dá F1 ≈ 18%, muito mais próxima do desempenho real. A média harmônica penaliza valores muito baixos em qualquer uma das duas parcelas.
⚖️
F1 é útil quando precisão e sensibilidade têm importância comparável. Se elas têm pesos diferentes no seu problema, use a forma generalizada Fβ, onde β controla quanta importância a sensibilidade tem em relação à precisão.
Fβ = ( 1 + β² ) · ( P · S ) / ( β² · P + S )
β = 0,5
Prioriza precisão
útil quando falsos positivos custam muito (ex.: sistemas de recomendação)
β = 1
Equilibra P e S
o F1 clássico — reduz para 2·P·S / (P+S)
β = 2
Prioriza sensibilidade
útil quando falsos negativos custam muito (ex.: diagnóstico de doenças)
Em problemas multiclasse, Fβ pode ainda ser calculado por classe e agregado (macro, micro, weighted) — cada agregação responde uma pergunta diferente.
